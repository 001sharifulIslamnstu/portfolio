## Attribution / content policy used in this portfolio

- Instructor roles are portfolio statements supplied by Md. Shariful Islam. Public event posts are used only as context and are **not** presented as independent proof that a specific post named him as instructor.
- A public event photo is not labeled as containing Md. Shariful Islam unless the source explicitly identifies him in that photograph.
- Where a stable original paper figure URL is not available, the Research Atlas displays a **Portfolio method schematic** rather than recreating a figure and calling it original.
- External media may disappear or change. The rest of the site remains functional if a remote source stops serving an image.
